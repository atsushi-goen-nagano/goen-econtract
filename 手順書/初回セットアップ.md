# 電子契約書アプリ 初回セットアップ（ご自身で・1回だけ）

所要：合計40分ほど。順番どおりに進めてください。途中で分からなくなったら、どの番号で止まったかを教えてください。
使うGoogleアカウントは **受領書アプリと同じ「あ」のアカウント**（共有ドライブ「03310002_GOEN様_小口社長_…」に入っているもの）です。

---

## A. 画面の公開先（GitHub Pages）
Claude Code が GitHubリポジトリ `goen-econtract` を作って公開します。公開URLは
**https://atsushi-goen-nagano.github.io/goen-econtract/** です（Bで使います）。
※ 公開されるのは画面のHTMLだけ。お客様の情報やPDFは一切GitHubに載りません。

## B. Googleの「クライアントID」を作る（10分）
「Googleでログイン」ボタンを動かすための鍵です。

1. 「あ」のアカウントでログインした状態で https://console.cloud.google.com/ を開く
2. 画面上部の「プロジェクトを選択」→「新しいプロジェクト」→ 名前 `GOEN-Keiyakusho`（日本語は使えない。半角英字とハイフンのみ）→ 作成
3. 左メニュー「APIとサービス」→「OAuth同意画面」
   - 「開始」→ アプリ名 `GOEN電子契約書`、ユーザーサポートメール＝自分のGmail
   - 対象ユーザー：**外部**（個人Gmailで使うため）
   - 連絡先メール＝自分のGmail → 作成
   - 「対象ユーザー」の画面で **「アプリを公開」**（テスト状態のままだと許可した人以外は使えず、7日でログインが切れます）
4. 左メニュー「クライアント」→「クライアントを作成」
   - アプリケーションの種類：**ウェブ アプリケーション**
   - 名前：`電子契約書 画面`
   - 承認済みの JavaScript 生成元 → 「URIを追加」で **https://atsushi-goen-nagano.github.io** を入れる
   - 作成 → 出てきた **クライアントID（…apps.googleusercontent.com）をコピー**して、Claude Code に貼ってください
     （シークレットは使いません。閉じてOK）

## C. GASプロジェクトを作る（10分）
1. https://script.google.com/ を「あ」のアカウントで開く →「新しいプロジェクト」→ 名前 `GOEN電子契約書`
2. 左の歯車「プロジェクトの設定」→「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック
3. エディタで次の4ファイルを作り、`gas/` の同名ファイルの中身を **丸ごと貼り付け**（ファイルは Claude Code が開いて渡します）
   - `appsscript.json`（既存を上書き）
   - `Code.gs`（既存のコード.gs を名前変更して上書き）
   - `Logic.gs`（＋ボタン → スクリプト）
   - `Template.gs`（＋ボタン → スクリプト）
4. 歯車「プロジェクトの設定」→ 下の「スクリプト プロパティ」→「スクリプト プロパティを追加」で3つ入れる
   | プロパティ | 値 |
   |---|---|
   | `OAUTH_CLIENT_ID` | BでコピーしたクライアントID |
   | `ALLOWED_EMAILS` | 使ってよいGmail（カンマ区切り。まずは自分のGmail） |
   | `ADMIN_EMAILS` | 自分のGmail（お客様名で検索できる人） |
5. エディタに戻り、関数の選択で **`setupAll`** を選んで「実行」
   - 初回は「承認が必要」→ 自分のアカウント → 「詳細」→「GOEN電子契約書（安全ではないページ）に移動」→ 許可
   - 実行ログに「OK」と、ひな形Doc・契約一覧のリンクが出れば成功
   - 「共有ドライブが 0 件」と出たら、`listSharedDrives` を実行してログの「小口社長」のIDをスクリプト プロパティ `SHARED_DRIVE_ID` に入れ、もう一度 `setupAll`
6. 関数 **`testSamplePdf`** を実行 → ログのリンクからテストPDFを開き、次を確認
   - 右上に赤い「控」の枠 ／ 全ページ下部に控えの文言 ／ クーリングオフが赤枠・赤字 ／ 文字が読める大きさ
7. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車 →「ウェブアプリ」
   - 説明：`v1` ／ 実行ユーザー：**自分** ／ アクセスできるユーザー：**全員**
   - 「デプロイ」→ 出てきた **ウェブアプリのURL（…/exec）をコピー**して Claude Code に貼ってください

## D. 画面に鍵とURLを入れる（Claude Code がやります）
Bのクライアント ID と CのウェブアプリURLを `docs/index.html` に入れてGitHubへ反映します。

## E. info@goen-nagano.com から送れるようにする（10分・あとからでも可）
設定するまでは「あ」のGmailアドレスから送られ、返信先だけ info@ になります。
1. Gmail（「あ」のアカウント）→ 右上の歯車 →「すべての設定を表示」→「アカウントとインポート」
2. 「他のメールアドレスを追加」→ 名前 `株式会社GOEN`、メール `info@goen-nagano.com`、「エイリアスとして扱います」にチェック → 次へ
3. SMTPサーバー：Xserverのサーバーパネル「メールアカウント設定」に書いてある値
   - SMTPサーバー `svXXXX.xserver.jp`（サーバーパネルの「サーバー情報」）／ポート `465`／SSL
   - ユーザー名 `info@goen-nagano.com`／パスワード＝そのメールのパスワード
4. info@ に届く確認メールのリンクを押す
5. GASで `checkMailAlias` を実行 →「info@ 使えます」と出れば完了

## F. iPadに入れる
1. iPadのSafariで **https://atsushi-goen-nagano.github.io/goen-econtract/** を開く
2. 共有ボタン →「ホーム画面に追加」→ 名前「電子契約書」
3. ホーム画面のアイコンから開き、Googleでログイン → 「テスト 太郎」で1件、締結まで通す
   - 共有ドライブ「2026年11月／90_その他／電子契約書」にPDFが入る
   - 「電子契約書（ひな形・一覧）」の契約一覧スプレッドシートに1行入る
   - メールを選んだ場合は控えメールが届く

## スタッフを増やすとき
- 使える人を増やす：スクリプト プロパティ `ALLOWED_EMAILS` にその人のGmailをカンマ区切りで追加
- 署名画面の担当者名を増やす：`Code.gs` の `STAFF_LIST` に名前を追加 → 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ

## 契約書の文面を直すとき（行政書士さんの修正）
- Googleドキュメント「電子契約書ひな形」（共有ドライブ／電子契約書（ひな形・一覧））を直接編集
- `《…》` の印は消さない・増やさない。直したら GAS で `checkTemplate` を実行するか、アプリのホームに注意が出ていないかを見る
- 「控」枠・フッターの文言・クーリングオフの赤枠は法律上の決まりなので消さない
